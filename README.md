Mais uma _textura_ sendo feita por mim.
Talvez eu faça um _port_[^2] dela para a **Java Edition** também (mas provavelmente não, por alguns motivos).
Este ___RP___ [^1] é o exemplo de projeto na minha série (_ou curso_) de texturas MCPE.

# O que faz eu não poder _portar_ esta textura para a Java Edition?
- Primeiro, _hackearam_ a conta Microsoft do meu pai (e só ele tem o jogo comprado).
  - Muitos sabem que não precisa ter uma conta com o Minecraft comprado para jogar na versão Bedrock.
  - Mas isso não se aplica ao Java, ou seja, não consigo acessar o jogo por ter perdido o acesso àquela conta.

- Segundo, eu não sei nem o básico para criar uma textura para o Java.
  - Muita coisa que funciona no Bedrock também vale pro Java (eu acho).
  - Mas o problema mesmo é que eu quase não jogo lá (ainda menos depois _daquilo_).
  - Então eu não iria animar para gastar tanto tempo fazendo isso...

### Para quem gosta da Java Edition, me perdoe...
Mas não vai ser dessa vez que eu vou criar um ___RP___ para essa versão do jogo.

# Por que dei início a este projeto?
Primeiramente, é porque eu já queria fazer uma textura com a temática de azul e rosa há um bom tempo.
E também, eu tive uma inspiração muito grande e valiosa!
